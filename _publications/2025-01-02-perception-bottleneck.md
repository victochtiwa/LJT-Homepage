This work examines the perception bottleneck in Vision-Language Models (VLMs) when applied to chart understanding tasks. The study identifies key limitations in how VLMs perceive and interpret visual data presented in chart form, providing insights into potential improvements for VLM architecture and training.

GitHub code repository: [Vision4Chart](https://github.com/Vicent0205/Vision4Chart)
